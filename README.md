# أذكار الصباح والمساء 🌙

موقع ثابت (صفحة واحدة `index.html`) يعرض أذكار الصباح والمساء الصحيحة بمصادرها، مع:
- تكبير / تصغير الخط
- ثيم دارك / لايت
- خط IBM Plex Sans Arabic (هوية ثمانية)
- عدّاد لكل ذكر + مسبحة إلكترونية 33 مرة
- حفظ التقدم في `localStorage`

## النشر عبر GitHub Pages
1. ارفع `index.html` و `.nojekyll` إلى مستودع باسم `athkar-morning-evening`.
2. من `Settings > Pages` اختر:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` ثم `Save`.
3. الرابط سيكون:
   `https://USERNAME.github.io/athkar-morning-evening/`

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح، لا يحتاج سيرفر.
